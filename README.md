# Light & Shape · 光与形

An interactive, bilingual (English / 中文) study of the art direction, visual philosophy and story of Bungie's **Destiny 2**, across every expansion from The Red War to Renegades.

一份可互动的中英双语研究：Bungie《命运2》的美术方向、视觉哲学与故事，覆盖从红色战争到 Renegades 的全部资料片。

- Pure static site (HTML/CSS/JS), no build step. Open `index.html` or host on GitHub Pages.
- All illustrations are original CSS/SVG abstractions. No game artwork is reproduced.
- Keyboard: `←` `→` move between sections (inside the Expansions section they step through expansions), `L` toggles language.
